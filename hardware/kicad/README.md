# ASCAM-1 in KiCad

`ascam1.net` is a KiCad netlist of the full rev 2 board: 64 parts, 40 nets, and
177 pin connections, each with its footprint. It is generated by
`make_netlist.py`, which looks up every pin number by name in the official KiCad
symbol libraries and checks it against the footprint's pads. `NETLIST.md` is the
same data in a readable table, and `../bom.csv` comes from the same script.

The generator used the KiCad 7.0 libraries. The symbols and footprints it uses are
standard parts that also exist in KiCad 10. If a name has changed, the import step
below lists it, and you choose the equivalent footprint. The netlist has not yet
been imported into a real KiCad, so treat the first import as its test.

## Step 1: start the PCB from the netlist (about 10 minutes)

1. In KiCad 10: **File > New Project**, save it in this folder as `ascam1`.
2. Open the **PCB Editor**, then **File > Import > Netlist...**, choose
   `ascam1.net`, and click **Load and Test Netlist** and then **Update PCB**.
   All 64 footprints appear in a pile, with their connections shown as ratsnest lines.
3. **File > Board Setup > Physical Stackup:** 4 copper layers, 1.6 mm.
   Make layer 2 (In1.Cu) a solid ground plane.
4. Draw the outline on **Edge.Cuts**: a 70 x 45 mm rectangle.

## Step 2: place and route (the part that needs you)

Follow `../figures/board_top_annotated.png` for placement:

- **Left:** J5 USB-C on the left edge, then U1, C1, and C2. Put R1 (the shunt)
  next to J1 on the top edge.
- **Middle:** U2 (the MCU), with Y1, C10, and C11 close to pins 5 and 6. Put one
  100 nF cap (C4 to C7) on each VDD or VDDA pin, as close as possible.
- **Right:** the four branches in a column. Each one has an AND gate, a MOSFET,
  and R_LOAD, plus an inverter, a second MOSFET, and R_COMP for branches 1 to 3.
- **Edges:** J1 and J2 on the top edge, J3 on the bottom edge, and the four M3
  mounting holes in the corners.

The rules that matter for the measurement:

- **Shunt sense:** route TP3 and TP4 (the Kelvin sense pads) as a short, tight
  pair from the two shunt pads. Keep the path from R1 to C3 to J1 short.
- **EM loop:** draw the loop yourself as a single top-layer trace. It starts at
  TP1, circles U2 at about 5 mm radius, and ends at TP2 (ground). Keep other
  traces from crossing it.
- **Branches:** keep each load branch close to U2's supply pins, so its current
  flows where the loop can sense it.
- **Clock traces:** keep the MCO trace (PA8 to U3, U4, and R8) short; it carries
  32 MHz.
- **Checks:** run DRC before sending the board to a fab.

## Step 3: draw the schematic (optional but recommended)

Draw it in the Schematic Editor using `../figures/schematic_sheet*.png` and
`NETLIST.md` as the guide. Keep the same reference designators (R1, U2, Q1 and so
on). Then **Tools > Update PCB from Schematic** keeps your placed layout. From then
on, the schematic, not `ascam1.net`, is the source of truth.

## Step 4: send it back

Save the project here (`ascam1.kicad_pro`, `.kicad_sch`, `.kicad_pcb`) and push.
The files are plain text, so the next review can check them against
`NETLIST.md`, the SPICE model, and the BOM, and CI can run KiCad's ERC and DRC on
every push.

## Regenerating

```bash
python hardware/kicad/make_netlist.py
```

This needs the KiCad symbol and footprint libraries. On Linux, install
`kicad-symbols` and `kicad-footprints`. Otherwise, point the `KICAD_SYMBOL_DIR`
and `KICAD_FOOTPRINT_DIR` environment variables at your KiCad library folders.
